WAVE agent-video demo

An agent speaks, and video appears

Produced video

4.3-second clip — WAVE voice narration + Big Buck Bunny source, created entirely through the live production API

Pipeline

Step 1

Synthesize narration

POST /v1/voice {text} → real MP3 audio from WAVE's neural TTS, served as audio/mpeg

Step 2

Create clip

POST /v1/clips {source, in, out} → the gateway accepts a source recording id + relative time window, returns a clipId

Step 3

Clip engine

Cloudflare Media Transformations reads the source via a presigned URL, transcodes the window, and writes the result to <org>/clips/<clipId>/clip.mp4

Step 4

Delivery

The response includes a signed URL (media.wave.online/...?exp=&sig=) — 200 video/mp4, HMAC-authenticated, time-limited

Run it

Reproduce the full pipeline with one command:

export WAVE_API_KEY=wave_live_...
export WAVE_ORG_ID=<your-org-id>
export WAVE_SOURCE_RECORDING_ID=<recording-id>

node demo.mjs all

Or run individual steps:

node demo.mjs synthesize    # MP3 narration
node demo.mjs create-clip   # signed delivery URL
node demo.mjs delivery      # produce clip + download

How it works

The clip is created from a registered source recording in iso_recordings — an org‑scoped R2 recordings store. The gateway's internal registry (POST /v1/internal/recordings/register, service‑token gated) allows any ingest protocol (SRT, RTMP, WHIP, MoQ, direct upload) to deposit bytes and register their location, making them immediately clip‑able.

Once registered, POST /v1/clips triggers the clip engine — a Cloudflare Media Transformations worker that resolves the source to a presigned R2 URL, transcodes the requested time window, and writes the output to the wave‑clips R2 bucket. Private clips are served via HMAC‑signed delivery URLs that wave‑media‑edge verifies at request time.
